### Лабораторна робота №7

**Назва:** Розробка веб-інтерфейсів та сервісів інтеграції (CSP, REST, SOAP) в InterSystems IRIS

---

### Мета роботи :

Освоїти методи взаємодії з базою даних InterSystems IRIS через веб-технології, реалізувати користувацький інтерфейс за допомогою сторінок CSP, розробити RESTful API для обміну даними у форматі JSON та впровадити SOAP веб-сервіс для міжпрограмної взаємодії.

---

### Вихідні дані

Для реалізації застосовано класи та компоненти системи керування бібліотекою:

- Library.Book (основний об'єкт керування)
- Library.REST (брокер для обробки REST-запитів)
- Library.SOAP (сервер веб-сервісів)
- BookManager.csp (веб-інтерфейс сторінки)

Класи та сервіси забезпечують:

- Прямий доступ до SQL через CSP
- Обробку HTTP-методів GET, POST, DELETE у REST
- Публікацію методів через WSDL у SOAP
- Клієнтську логіку на JavaScript (Fetch API)

---

### Основні Завдання Роботи

---

### 1. Веб-інтерфейс CSP (Direct Access)

Створено динамічну сторінку BookManager.csp для керування списком книг.

Функціонал сторінки:

- Використання серверного коду InterSystems ObjectScript всередині HTML
- Direct SQL Access: відображення таблиці об’єктів за допомогою SQL-курсора (&sql) безпосередньо з бази даних
- Формування HTML-таблиці на основі результатів SQL-запиту
- Інтеграція з REST-клієнтом для виконання операцій видалення без перезавантаження сторінки

---

### 2. Створення RESTful сервісу

Розроблено клас Library.REST, що успадковується від %CSP.REST.

Характеристики сервісу:

- UrlMap: налаштовано маршрути для отримання даних (GET), створення (POST) та видалення (DELETE) книг
- JSON Serialization: реалізовано конвертацію об’єктів Library.Book у формат JSON за допомогою динамічних об’єктів
- Web Application: сервіс зареєстровано в системі за шляхом /api/library

---

### 3. Реалізація SOAP веб-сервісу

Створено клас Library.SOAP для підтримки протоколу SOAP.

Можливості сервісу:

- Web Methods: оголошено методи SaveBook та DeleteBook, доступні для зовнішніх викликів
- WSDL: автоматична генерація XML-опису сервісу для створення клієнтів у сторонніх системах
- Забезпечення суворої типізації даних при передачі параметрів

---

### 4. Клієнтські додатки

Реалізовано два типи клієнтів для взаємодії з сервісами:

- REST Client (JavaScript):
  - Використання fetch() для відправки асинхронних запитів до API
  - Виконання CRUD-операцій без перезавантаження сторінки

- SOAP Client (ObjectScript):
  - Реалізовано метод CallSoapDelete
  - Демонстрація програмного керування об’єктами через проксі-класи сервісу

---

### Результати

- Реалізовано повноцінний CRUD-інтерфейс для роботи з книгами через браузер
- Забезпечено можливість інтеграції бібліотечної системи з іншими додатками через REST (JSON) та SOAP (XML)
- Продемонстровано роботу прямого доступу до даних у веб-середовищі
- Використано сучасні API-клієнти для асинхронної взаємодії
