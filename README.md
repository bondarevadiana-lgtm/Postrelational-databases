### Лабораторна робота №5

**Назва:** Обчислювані властивості, Автоматична генерація даних та Модульне тестування в InterSystems IRIS

### Мета роботи :

Поглибити навички роботи з об’єктною моделлю InterSystems IRIS шляхом реалізації автоматично обчислюваних властивостей (Calculated Properties), створення сервісу для автоматичної генерації тестових даних та розробки системи модульного тестування (Unit Testing) для перевірки цілісності даних і бізнес-логіки бібліотечної системи.

---

### Вихідні дані

Для реалізації застосовано класи системи керування бібліотекою:

- Library.Item (базовий клас для книг та журналів)
- Library.Book
- Library.Magazine
- Library.Member
- Library.Collection

Класи містять:

- Обчислювані властивості (Calculated Properties)
- Required та Unique властивості
- Колекції типу list of objects
- Бізнес-логіку обмежень (BorrowLimit)
- Методи для роботи з об’єктами
- Підтримку модульного тестування

---

### Основні Завдання Роботи

### 1. Додавання завжди обчислюваної властивості

У клас Library.Item додано обчислювану властивість IsNewRelease.

- Тип: %Boolean
- Логіка: автоматично визначає, чи є видання новим (випущеним протягом останніх 2 років)
- Реалізація: створено Getter-метод IsNewReleaseGet, який порівнює PublishedYear з поточним роком системи

---

### 2. Автоматична генерація даних

Створено утилітарний клас Library.Utils з методом GenerateData.

Функціональність:

- Автоматичне створення об’єктів класів Library.Book, Library.Magazine та Library.Member у циклі
- Виправлено помилку формату часу: для властивості RegisteredDate (%TimeStamp) використано $zdt($h, 3)
- Усі створені об’єкти автоматично додаються до колекцій Items та Members класу Library.Collection
- Дані коректно зберігаються в базі даних

Приклад запуску генерації даних:
```
Do ##class(Library.Utils).GenerateData(10)
```



---

### 3. Модульне тестування (Unit Testing)

Створено клас Library.Tests, який успадковується від %UnitTest.TestCase.

Реалізовані тести:

- Створення об’єктів: перевірка успішного збереження при заповненні всіх Required властивостей
- Обмеження: тестування бізнес-логіки методу BorrowItem та ліміту BorrowLimit
- Унікальність: перевірка спрацювання індексів Unique для ItemID та MemberID
- Видалення: тестування поведінки системи при видаленні об’єктів, що входять до колекцій (Relationship / List behavior)

Приклад запуску тестування:

```
Set ^UnitTestRoot = "/usr/src/lab4"
Do ##class(%UnitTest.Manager).RunTest("Library")
```
