### Лабораторна робота №4
**Назва:** Створення, Ініціалізація та Збереження Об’єктів у Базі Даних
### Мета роботи : 
На основі діаграми класів, розробленої в Лабораторній роботі №3, створити відповідні класи в середовищі InterSystems ObjectScript, створити об’єкти цих класів, заповнити їх усіма властивостями з урахуванням обмежень та зберегти в базу даних

### Вихідні дані

Для реалізації застосовано класи з попередньої лабораторної:

- Library.Item (абстрактний клас)
- Library.Book
- Library.Magazine
- Library.Member
- Library.Collection

Класи містять:
- Required властивості
- Unique властивості
- Обмеження (minlen, maxlen, minval, maxval)
- Стрім-властивості (%Stream.GlobalCharacter)
- Колекції типів list of objects
- Зв’язки one-to-many та parent-children

### Основні Завдання Роботи
###  1. Створити класи в системі
Усі класи побудовані згідно з діаграмою класів ЛР3 та реалізовані.
### 2. Створити мінімум 2 об’єкти кожного класу
Для кожного класу створено щонайменше по два екземпляри:
- Дві книги
- Два журнали
- Два читачі
- Дві бібліотечні колекції

### 3. Всі обмеження виконані
Усі значення властивостей були підібрані відповідно до:
- minlen / maxlen
- minval / maxval
- Required
- Unique
- Типу даних

### 4. Зберегти всі об’єкти в базу даних
Всі створені екземпляри були збережені у сховище через метод %Save()
Клас для Автоматичного створення даних було створено окремий сервіс CreateObjects.CreateDemoData

Приклад запуску:
DO ##class(CreateObjects.CreateDemoData).Run()
