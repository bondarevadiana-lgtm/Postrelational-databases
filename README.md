## Лаб робота №2 (ObjectScript: Глобали та Списки)
**Назва:** Робота з Глобальними Змінними та Внутрішніми Списками  
### Мета роботи
Продемонструвати створення та роботу з глобальними змінними (Global) із використанням різних типів індексів та зберіганням даних у форматі внутрішніх списків.

### Основні Функціональні Можливості
**Створення Глобала:**  
Створено глобальну змінну ^Library для зберігання інформації про позики книг.

Глобал використовує чотири рівні індексів з різними типами даних:
1. BranchID (Число)  
2. BookTitle (Рядок)  
3. BorrowDate (Дата/Рядок)  
4. MemberID (Число)

**Використання списків:**  
Дані позики (BorrowerName, DueDate, Condition) зберігаються як внутрішній список ($LISTBUILD).

**Вбудовані функції для роботи зі списками :**
- $LISTBUILD: Створення списку  
- $LISTGET: Зчитування елементів списку за позицією  
- $LISTLENGTH: Визначення кількості елементів у списку  
- $LISTFIND: Пошук значення у списку  
- $LISTTOSTRING: Конвертація списку у рядок для виведення
