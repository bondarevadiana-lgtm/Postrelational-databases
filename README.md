## Лаб робота №1 (Python: ООП)
**Назва:** Демонстрація Основ Об'єктно-Орієнтованого Програмування (ООП)  
**Мова:** Python  

### Мета роботи
Продемонструвати ключові концепції ООП (успадкування, абстракція, інкапсуляція, поліморфізм) шляхом створення моделі Бібліотеки та її об'єктів.

### Реалізовані Концепції
**Успадкування та Абстракція:**  
Класи Book та Magazine успадковуються від абстрактного класу LibraryItem.

**Інкапсуляція (Властивості):**
- Публічні: title, author, pages  
- Захищені: _year  
- Приватні: __id (доступ через Property id)  
- Приватний метод: __can_borrow() у класі LibraryMember

**Поліморфізм (Перевантаження):**  
Метод display_info() у класі Book перевантажений за допомогою додаткового параметра show_author.

**Складові Властивості:**  
- LibraryMember містить список об'єктів borrowed_items (список запозичених LibraryItem)  
- Library містить списки об'єктів items та members
